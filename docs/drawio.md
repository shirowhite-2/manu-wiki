# draw.io 链接与图表预览

> 当前整合分支已升级为策略 **12**，已安装策略 10 / 11 也须重建组件和镜像，按[最新升级命令](admin-tools.md#现有-mac-实例升级8081)执行。下文仅界面更新的描述是该功能初次引入时的情况。


编辑者可在草稿编辑器上方的 **外部链接，自动识别** 中粘贴发布／分享链接，点击 **插入链接**。文章保存的是普通链接，无需手写 HTML、嵌入宏或额外授权。保存并预览后，链接旁提供 **预览图表 / Preview diagram**；点击后在页面内加载只读查看器。原链接保留，可在新标签页跳转。知识库正式文章在审核通过后显示同样的链接和预览入口。

同一输入框也接受 GitHub、Bitbucket 等普通链接，点击后打开原网站，不提供代码或仓库预览。已存在于正文中的受支持 draw.io 分享链接也会提供预览入口，无需重新插入。源码编辑可以直接使用 XWiki 原生链接语法。代码块中的示例链接不转换。

## 生成可预览的链接

在 draw.io 中选择 **文件 → 导出为 → URL**，或 **文件 → 发布 → 链接**，复制生成的 HTTPS 链接。推荐带图表内容的链接（`#R...`），无需另行公开网盘文件。它展示的是生成链接时的图表快照；后续修改原图，需要重新生成链接并更新 Wiki 草稿、送审。

也支持 `#U...` 和 `?url=...` 指向公开 HTTPS 图表文件的分享链接。这类预览随源文件变化，不是审批时的固定快照。外部源文件的共享权限由源系统维护，Wiki 不会将它复制到本地或替用户登录。

支持官方根地址 `app.diagrams.net`、`viewer.diagrams.net` 及旧版 `app.draw.io`、`viewer.draw.io`、`draw.io`、`www.draw.io`。需要登录的 Google Drive / OneDrive 链接、只打开编辑器的空链接等保留跳转，并提示如何获得可预览链接。不对私有图表强制改为公开。公司自建实例须另行配置集成，不能把任意网站当作图表嵌入。

## 查看行为

查看器在读者点击 **预览图表** 后才加载；页面初次打开不发送图表预览请求。预览使用 draw.io 官方外部服务，可能受网络、源文件授权、浏览器或站点 CSP 限制。即使预览不可用，原链接仍可打开；预览区域始终显示这个提示，不把 iframe 的加载事件当作图表成功渲染的证明。

查看器在单独的 iframe 内运行，禁止接管 Wiki 顶层页面；不向外部页面发送 Wiki 的引荐地址，不将作者提供的脚本／插件／编辑器配置参数带入预览。Wiki 服务器不代理下载外部链接。分享链接中的图表内容对能阅读该文章的人可见；本功能不改变草稿、审核或正式文章权限。

界面按钮与说明随 English / 中文切换；原作者的链接文本和图表正文保持原样。**收起图表** 可关闭页内展示。此功能提供链接和查看，不在 Wiki 内编辑或自动保存 draw.io 源文件。

## 部署

链接功能本身只更新界面。当前分支要求策略 10；尚未升级的实例须先按[编辑锁部署说明](edit-locks.md)完整构建组件和镜像。已运行策略 10 的实例后续更新界面时，可直接执行完整安装器：

```bash
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost \
python3 scripts/apply_workflow.py --base-url http://127.0.0.1:8081 --apply
```

安装器创建／更新 `LuxPedia.Code.DrawioScript` JavaScript 扩展，并同步中英文帮助。完成后强制刷新浏览器。

回归使用本地浏览器夹具，并拦截外部查看器请求，验证插入、链接保留、按需加载、地址校验、私有链接降级、中英文、窄屏和动态正文更新。夹具不包含真实 XWiki 的富文本到 Wiki 转换，也不验证外网图表渲染。实际实例需使用 editor 创建含真实发布链接的草稿，保存预览、送审并发布后，由 reader 检查跳转、图表预览和移动端显示。

参考：[draw.io 发布链接说明](https://www.drawio.com/docs/manual/export/publish-link/)、[嵌入说明](https://www.drawio.com/docs/manual/export/embed-html/)。
